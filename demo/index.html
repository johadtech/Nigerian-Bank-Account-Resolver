What this demo can prove

It validates the NUBAN checksum against locally configured prefixes and displays documented phone-account capabilities using local JSON and image assets.

What it cannot prove

A ten-digit NUBAN does not universally encode its bank. Multiple matches are shown as ambiguous; the demo never claims account ownership or performs a live name enquiry.
